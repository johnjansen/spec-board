Welcome to spec-board

Desktop application for viewing and managing spec-kit artifacts

Getting Started

To begin, open a specs/ directory from your spec-kit project.

The directory should contain numbered feature folders like 001-feature-name/, each with spec.md, plan.md, and/or tasks.md files.

Or use File → Open Folder from the menu

What you can do:

  • ✓ Browse feature specifications, implementation plans, and task breakdowns
  • ✓ View rich markdown rendering with syntax highlighting
  • ✓ Edit spec files inline with live preview
  • ✓ Visualize tasks in Kanban board view
  • ✓ Track progress with completion indicators

Built with ❤️ using spec-kit and Claude Code
